# CBS 模块二：核心信号优先级分析

> 版本: v1.0 | 日期: 2026-04-14
> 定位: 从基金真实投研需求出发，回答"模块二最应该抓哪些信号"，为首版设计提供选型依据。

---

## 零、分析前提

在拆解信号之前，先锚定三个关键约束：

| 约束 | 内容 |
|------|------|
| **团队需求结构** | 80% 验证已有标的 + 20% 发现新机会 |
| **老板要求** | 复杂度砍掉 1/2 到 2/3，"少而精" |
| **核心痛点** | 建仓信号、撤退信号、资金层验证、主力意图变化 |

因此，**信号的选择标准不是"技术上能不能识别"，而是"基金投研会议上，分析师会不会因为这个信号改变决策"。**

---

## 一、最值得抓的 7 类信号候选（按优先级排序）

### P0-1: 高质量实体建仓信号（Smart Money Accumulation）

| 维度 | 内容 |
|------|------|
| **一句话定义** | 白名单中的高质量买方（机构/匿名高手）对某 Token 发生真实买入行为，且买入规模相对该实体自身历史仓位显著 |
| **为什么对基金最重要** | 这是基金最原始、最直觉的需求——"聪明钱在买什么"。一个历史胜率 65%+ 的匿名高手花自己 15% 仓位买入某 Token，这就是最硬的链上 Alpha。团队 80% 的工作是验证已有标的，而这个信号可以直接回答"有没有聪明钱也在下注同一个标的" |
| **偏向验证 vs 发现** | **两者兼备，但首版侧重验证。** 当信号命中团队已研究标的 = 强验证；命中未知标的 = 发现机会 |
| **实现复杂度** | **中。** 需要：白名单管理（简化版）、DEX Swap 买入识别、实体历史仓位基线。不需要完整画像体系，首版可用"仓位占比"一个维度判断 conviction |
| **V5 对应** | 指标 1（净流入）+ 行为匹配分（HIGH_CONVICTION）+ A1/A3 实体分类 |

---

### P0-2: 高质量实体撤退/清仓信号（Smart Money Distribution）

| 维度 | 内容 |
|------|------|
| **一句话定义** | 白名单高质量实体对某 Token 发生真实卖出、大比例减仓、或出现卖出前兆行为（冷→热转移、CEX 入金） |
| **为什么对基金最重要** | 撤退信号的投研价值甚至高于建仓信号——错过一个建仓机会只是少赚，但忽略一个撤退信号可能是致命亏损。当团队持仓的某个标的突然被多个聪明钱减仓，这是最高优先级的风险预警 |
| **偏向验证 vs 发现** | **纯验证。** 核心场景是"我们已经持仓的标的，有没有聪明钱在跑" |
| **实现复杂度** | **中。** 与建仓信号共用同一套 Event Layer 基础设施，额外需要识别"冷→热转移"和"CEX 入金"两种前兆行为 |
| **V5 对应** | 指标 1（净流出面）+ 指标 6（冷→热转移、大额入所）+ B1 解锁行为 |

---

### P0-3: 多实体独立共振信号（Independent Convergence）

| 维度 | 内容 |
|------|------|
| **一句话定义** | 多个无关联的白名单高质量实体在短时间窗口内（如 24-72h）对同一 Token 执行同向操作（同时建仓或同时撤退） |
| **为什么对基金最重要** | 单个聪明钱的操作可能有各种原因（对冲、流动性管理、个人原因），但当 3-5 个互不关联的高质量实体同时买入同一 Token，信号置信度呈指数级提升。这是"独立验证"的链上版本——基金做研究最怕的就是信息来源单一，而链上共振天然提供多源验证 |
| **偏向验证 vs 发现** | **验证和发现五五开。** 当共振发生在已研究标的上 = 最强验证信号；当共振发生在未知标的上 = 最高质量的发现信号（多个聪明钱同时发现了你没注意到的东西） |
| **实现复杂度** | **低。** 这是建仓/撤退信号的聚合层，不需要新的数据管道。只需要在信号 1、2 的基础上做时间窗口聚合 + 实体去关联判断（确认不是同一实体的多个地址） |
| **V5 对应** | 指标 3（参与动态）+ 推送条件"多独立实体 4h 内同向操作" |

---

### P0-4: 做市商异常行为信号（Market Maker Anomaly）

| 维度 | 内容 |
|------|------|
| **一句话定义** | 做市商发生非常规行为——撤出做市、新增做市、区间大幅上移/下移、自营方向性交易、多做市商同向操作 |
| **为什么对基金最重要** | 做市商是市场微观结构的核心。常规做市是噪音（必须过滤），但做市商的异常行为是极高价值信号：(1) 撤出做市 = 预知重大风险，(2) 多做市商同向操作 = 信息不对称极大，(3) 做市商自营交易 = 用自己的钱表达观点。这些信号极难从传统投研获得，是链上分析的独特优势 |
| **偏向验证 vs 发现** | **主要验证，兼顾预警。** 做市商异常通常发生在已有一定关注度的标的上，核心价值是"这个标的是不是要出大事了" |
| **实现复杂度** | **中高。** 需要准确识别做市商地址（依赖 Arkham/Nansen 标签），区分常规做市 vs 异常行为。首版可只做"撤出/新增做市"和"多做市商同向"两个子信号，省略区间分析 |
| **V5 对应** | 指标 6（结构性事件中的做市商部分）+ C1 分类 |

---

### P1-5: 供给侧压力信号（Supply-Side Pressure）

| 维度 | 内容 |
|------|------|
| **一句话定义** | 低成本筹码持有方（B1 早期投资者/B2 项目方/Treasury）出现解锁后链上行为变化——转入 CEX、冷→热转移、链上 Perp 做空对冲 |
| **为什么对基金最重要** | 供给侧是价格的"天花板"。一个标的基本面再好，如果即将面临大规模解锁抛压，短期内也不适合建仓。团队持仓的标的如果其早期投资者开始将代币转入交易所，这是直接的减仓信号 |
| **偏向验证 vs 发现** | **纯验证。** 供给侧信号几乎只对已持仓或已研究标的有意义 |
| **实现复杂度** | **中。** 核心难点是 B1/B2 地址的准确识别（哪些地址持有低成本筹码）。首版可依赖 Arkham 的 VC/Foundation 标签，不自建溯源 |
| **V5 对应** | B1/B2 实体的行为监控 + 指标 6（层 2 事件）|

---

### P1-6: 交易所大额净流向信号（CEX Net Flow）

| 维度 | 内容 |
|------|------|
| **一句话定义** | 某 Token 在链上与 CEX 之间的大额资金净流动方向——大额净提币（看多）或大额净充值（看空） |
| **为什么对基金最重要** | CEX 净流向是加密行业最经典的资金信号之一，直觉清晰：大量代币流入交易所通常预示卖压，大量代币流出交易所预示惜售/囤积。虽然不是独家数据（Nansen/Glassnode 都有），但在 CBS 体系内将其与实体身份结合后（不只看 flow 方向，还看"谁在 flow"），价值显著提升 |
| **偏向验证 vs 发现** | **验证为主。** 主要用于确认已研究标的的资金供需状态 |
| **实现复杂度** | **低。** CEX 热钱包地址已被广泛标记，只需监控 Token 与已知 CEX 地址之间的 Transfer 即可。是最容易落地的指标之一 |
| **V5 对应** | 指标 4（交易所净流量）|

---

### P1-7: 新增高质量关注信号（First Touch by Smart Money）

| 维度 | 内容 |
|------|------|
| **一句话定义** | 一个高质量白名单实体首次与某 Token 产生交互（首次买入），尤其当该实体此前从未接触过该 Token 的任何操作 |
| **为什么对基金最重要** | "首次参与"是所有行为中 Alpha 最高的——它意味着该实体经过研究后做出了新的投资决策。相比加仓（可能只是惯性操作），首次建仓代表一个新的独立判断。如果该实体是机构买方（A1）首次参与某 Token，这对基金来说几乎是"必须看一眼"的事件 |
| **偏向验证 vs 发现** | **发现为主。** 这是 20% "发现新机会"需求的核心信号。当多个高质量实体首次参与一个团队没覆盖的 Token，这就是最值得研究的新标的 |
| **实现复杂度** | **低。** 在建仓信号基础上，只需额外维护每个实体的 token 交互历史列表，判断是否为首次。几乎无新增数据管道成本 |
| **V5 对应** | 指标 3 的子维度 3a（新增参与实体数）+ A1 机构首次参与推送条件 |

## 二、信号优先级总表

| 优先级 | 信号 | 核心回答的问题 | 验证/发现 | 实现复杂度 | 首版必须 |
|--------|------|----------------|-----------|------------|----------|
| **P0-1** | 高质量实体建仓 | 聪明钱在买什么？ | 两者兼备 | 中 | **是** |
| **P0-2** | 高质量实体撤退 | 聪明钱在跑什么？ | 纯验证 | 中 | **是** |
| **P0-3** | 多实体独立共振 | 多个聪明钱是否观点一致？ | 五五开 | 低 | **是** |
| **P0-4** | 做市商异常行为 | 市场结构是否要变？ | 验证+预警 | 中高 | **是（简化版）** |
| **P1-5** | 供给侧压力 | 低成本筹码要出来了吗？ | 纯验证 | 中 | 是（依赖标签质量） |
| **P1-6** | CEX 大额净流向 | 资金供需方向？ | 验证为主 | 低 | 是 |
| **P1-7** | 新增高质量关注 | 聪明钱发现了什么新东西？ | 发现为主 | 低 | 是 |

## 三、应当从首版中剔除或大幅简化的部分

以下是 V5 中有吸引力但**不应作为首版重点**的内容，以及具体理由：

### 1. 完整三层画像标签体系（V5 的 5.4 节）

**V5 设计**: A 层主风格 + B 层执行路径 + C 层状态，共 16 种标签，基于 17 项指标自动生成。

**为什么不急**: 画像的核心价值是提升信号的精确度（行为匹配分），但首版的信号本身还没跑通，过早投入画像精度优化是过度工程化。首版只需要一个"实体质量分"（基于历史胜率 + 规模 + 活跃度的简单加权），足以区分"值得关注的信号"和"噪音"。

**首版替代**: 单一 quality_score（0-100），基于 win_rate_all + avg_pnl + 总交易数 三个字段计算。

---

### 2. 行为匹配分（Behavior Match Score）的完整对比维度（V5 的 5.5 节）

**V5 设计**: 5 个维度（仓位、建仓方式、择时、标的匹配、历史类似操作）完整对比，输出 4 种标签。

**为什么不急**: 行为匹配分的精髓——"这次操作对这个实体来说是不是认真的"——可以用一个简化版本实现。首版只需要"仓位占比 vs 历史均值"这一个维度，就能覆盖 80% 的判断需求。

**首版替代**: conviction = position_size / avg_position_size。大于 1.2 = HIGH, 小于 0.5 = LOW, 其他 = NORMAL。

---

### 3. 持仓集中度分层分析（V5 的指标 5）

**V5 设计**: 三层持仓分析（鲸鱼层/中等层/零售层），叠加实体分类标签，计算各层占比变化。

**为什么不急**: 这需要全量持仓数据（不限白名单），数据量巨大，且对首版投研决策的增量价值有限。团队真正关心的不是"零售层占比增加了 3%"，而是"有没有聪明钱在买/卖"。

**首版替代**: 暂不实现。白名单实体的买卖信号已经隐含了"高质量资金方向"信息。

---

### 4. LP 行为与流动性动态的完整分析（V5 的指标 7）

**V5 设计**: 4 个子维度（池子深度变化、撤池检测、流动性集中度、流动性迁移），全量 LP 数据。

**为什么不急**: LP 分析需要专门的数据管道（V3 position NFT 追踪、pool 事件监听），实现成本高。且大部分 LP 信号与基金的核心决策（买不买、卖不卖）关联度较弱。

**首版替代**: 只保留"撤池 + 深度骤降"这一个高优先级风险信号（已归入做市商异常行为），其余 LP 细节推到 P1。

---

### 5. Perp 修正项（V5 的 7.3 节）

**V5 设计**: 用 Hyperliquid/GMX 的 Perp 净敞口做 CBS Score 乘数修正。

**为什么不急**: Perp 数据源（Hyperliquid API）本身可靠性待验证，且 Perp 仓位的归因困难——难以确认某个 Perp 仓位属于做市对冲还是方向性交易。V5 自身也标注为 Phase 2。

**首版替代**: 不实现。乘数 = 1。

---

### 6. 完整的 18 类实体二级分类（V5 的 4.3 节）

**V5 设计**: 5 大类 18 子类，含 E 类特殊观察（借贷/清算、托管/代持、治理/质押、稳定币发行方）。

**为什么不急**: 分类越细，维护成本越高，且很多子类（E2 托管、E4 稳定币发行方）对首版信号的贡献极小。

**首版替代**: 只需 4 类——A（主动买方）、B（潜在卖方/供给侧）、C1（做市商）、D（噪音过滤）。C2-C4 做穿透处理，E 类全部推到 P1。

---

### 7. 完整的信号回测框架（V5 的 M5）

**V5 设计**: 三窗口回测（+24h/+7d/+30d）、加权评分、画像反馈闭环、参数自动调优。

**为什么不急**: 回测是系统"自我优化"的能力，前提是系统已经在产生信号。首版应先保证信号能产出、能推送、人工能判断质量，再建立自动化回测。

**首版替代**: 人工记录信号准确率，每周复盘。回测自动化推到 P1。

---

### 8. 实体归因（Entity Resolution）的复杂方法（V5 的 4.2 节）

**V5 设计**: 4 种归因方法（Gas 来源分析、资金流聚类、时序行为聚类、合约工厂追踪）。

**为什么不急**: 实体归因是一个独立的技术难题，做好需要大量工程投入。首版直接使用 Arkham/Nansen 提供的已有归因结果即可（它们已经做了大量工作）。自建归因放到 P2。

**首版替代**: 直接使用第三方标签的实体-地址映射，辅以投研团队手动归因。

---

## 四、关于首版实现的架构建议

基于以上信号分析，首版 CBS 的**实际组件需求**可以收缩为：

| 组件 | V5 规模 | 首版规模 | 缩减比例 |
|------|---------|----------|----------|
| 实体分类 | 5 大类 18 子类 | 4 类（A/B/C1/D） | ~78% |
| 画像指标 | 17 项指标 + 三层标签 | quality_score 1 项 + conviction 1 项 | ~88% |
| 行为识别 | 买入 7 种 + 卖出 7 种 + 迁移 8 种 + 结构 7 种 + 噪音 6 种 | 买入 3 种 + 卖出 3 种 + 迁移 2 种 + 噪音过滤 | ~77% |
| CBS 指标 | 7 + 1 个指标 | 4 个核心指标 | ~50% |
| 推送触发条件 | 7 种 | 4 种 | ~43% |
| 回测系统 | 自动化三窗口 + 反馈闭环 | 人工记录 | ~95% |

**整体复杂度缩减约 60-70%**，符合老板"降低 1/2 到 2/3"的要求。

---

## 五、核心结论

从基金的真实需求出发，CBS 首版最应该抓的信号可以用一句话概括：

> **"谁在买、谁在卖、有没有人一起买/卖、做市商有没有异常。"**

这四个问题对应 P0 的四个核心信号（建仓、撤退、共振、做市商异常），覆盖了团队 80% 验证需求和基本的风险预警。

P1 的三个信号（供给侧压力、CEX 净流向、新增关注）是自然延伸，实现成本低，可在首版稳定后快速补充。

所有其他内容——完整画像体系、行为匹配分精细对比、持仓集中度、LP 全量分析、Perp 修正、自动化回测——都应该在首版信号跑通后，根据实际效果决定是否以及何时引入。

# CBS 模块二：首版核心信号原型深度分析

> 版本: v2.0 | 日期: 2026-04-14
> 角色: 基金投研负责人 × 数据产品架构师
> 目的: 在保留模块二核心价值的前提下，回答"首版最值得抓的核心资金信号原型到底是什么"

---

## 零、分析框架：为什么要从"业务结果"而非"技术指标"出发

V5 的问题不是方向错，而是它从"技术上能识别什么"出发，构建了一套完整但沉重的指标体系（7+1 指标、17 项画像、5×18 分类）。但基金投研的实际决策场景只有几个：

| 基金真实决策时刻 | 需要 CBS 回答的问题 |
|---|---|
| "我们看好标的 X，应该建仓吗？" | 有没有高质量资金也在买？下注认不认真？ |
| "我们持仓标的 Y，应该跑吗？" | 聪明钱有没有在撤？供给侧有没有新卖压？ |
| "NDS/ECS 提示标的 Z 有催化，可信吗？" | 链上资金行为是否支持这个判断？ |
| "有没有我们遗漏的重要标的？" | 有没有多个高质量实体不约而同看上了同一个东西？ |
| "这个标的的主力是不是变了心？" | 之前一直在买的人，是不是停了甚至反向了？ |

**首版 CBS 应该直接回答上面这 5 个问题。每个问题对应一类"业务结果型信号"，而不是一组抽象指标。**

以下分析严格遵循三个约束：
- **需求结构**: 80% 验证已有标的 + 20% 发现新机会
- **标的特征**: 偏价值型，有基本面/业务支撑，非纯 meme/情绪驱动
- **精简目标**: 保留核心价值，收缩复杂度 1/2 ~ 2/3

---

## 一、6 类核心资金信号原型候选

### 候选 1: 聪明钱方向性动作（Smart Money Directional Action）

**一句话定义**: 白名单高质量实体对某 Token 发生真实的、有意义规模的买入或卖出行为，且该行为相对该实体自身历史仓位习惯具有可辨识的"认真程度"。

**为什么对基金最重要**:

这是 CBS 存在的根本理由。一个历史胜率 62%、平均持仓 30 天的 A3 匿名高手，拿出 15% 仓位买入某 Token——这不是一条数据，这是一个经过验证的投资者用真金白银表达了一个方向性判断。对于团队来说，80% 的工作是验证已有标的，而这个信号直接回答："有没有聪明钱跟你做了同样的判断？"

同样重要的是反向：同一个实体开始卖出，或出现卖出前兆（冷→热钱包转移、大额 CEX 入金），这是团队需要立即评估的风险信号。卖出信号的非对称性极强——错过一个建仓机会只是少赚，忽略一个撤退信号可能是致命亏损。

**偏向验证 vs 发现**: 80% 验证 / 20% 发现。当信号命中团队已研究标的 = 最直接的验证；命中未知标的时，如附加"该实体首次参与该 Token"标记，则成为发现信号。

**误报风险**: **中**。主要来源：(1) 内部地址调仓被误读为方向性买卖；(2) OTC 预安排交易的链上部分看起来像主动建仓；(3) 跨协议迁移（如从 V2 迁到 V3）被误读为卖出+买入。缓解方式：基础的穿透过滤 + 同实体地址去重 + 最小金额门槛。

**工程复杂度**: **中**。需要：白名单地址库、DEX Swap 事件识别（主路径 3 种即可）、聚合器穿透、CEX 地址标记、基础的实体质量评分。不需要完整 17 维画像、不需要完整 BMS。

**历史上为什么有价值**:

这不是理论推导，而是加密市场反复验证过的模式。2020 年 DeFi Summer 之前，链上数据显示多个后来被证明是顶级基金的地址在 AAVE、COMP 上持续增持；2021 年 SOL 从 $3-5 起步时，链上可追踪到多个高胜率地址的早期重仓。反面也成立：2022 年 LUNA 崩盘前 4-6 周，多个历史高胜率地址已在减仓，而散户仍在追高。这类信号的历史有效性来自一个简单的逻辑——信息优势转化为资金行为比转化为公开叙事更早。

### 候选 2: 多主体独立共振（Independent Multi-Entity Convergence）

**一句话定义**: 在短时间窗口内（24-72h），多个被确认为无关联的白名单高质量实体对同一 Token 执行了同向的有意义操作。

**为什么对基金最重要**:

单个聪明钱的操作有无数可能的非信号原因——流动性管理、税务操作、对冲需要、个人财务事件。基金不应因为一个鲸鱼买了就跟进。但当 3-5 个互不关联的高质量实体在 48 小时内独立买入同一 Token，这在概率上几乎只有一种解释：**存在某个驱动力（信息、事件、基本面变化）同时被多个独立决策者捕获到了**。

这是情报分析中"多源独立验证"原则的链上实现。它把候选 1 从"有趣的线索"提升为"可操作的信号"。

**偏向验证 vs 发现**: **50/50**。共振发生在已研究标的上 = 最强验证（"不只我们一家这么认为"）；共振发生在未覆盖标的上 = 最高质量的发现信号（"多个聪明钱同时发现了一个我们没注意到的东西"）。

**误报风险**: **低**。这是所有候选信号中误报率最低的一类。要求多个独立实体同向，天然过滤了大部分噪音。主要风险：(1) 关联实体未被正确归因，看似独立实际是同一主体（如同一基金的多个地址）；(2) 跟随行为——后续实体不是独立判断而是看到第一个实体买入后跟风。缓解方式：实体去关联检查 + 时间窗口收紧（4h 内的操作更可能是独立的）。

**工程复杂度**: **低**。这是候选 1 的聚合层，不需要任何新的数据管道。在候选 1 产出的事件流上做时间窗口聚合 + 实体去关联校验即可。核心逻辑不超过 200 行。

**历史上为什么有价值**:

加密市场的"信息渗透"有一个独特的时间结构：重大基本面变化（协议升级、合作达成、监管变化）通常先被少数 insider 知道，然后在 24-72 小时内扩散到 5-15 个核心圈层参与者，最后才变成公开新闻。链上共振捕获的恰好是这个"扩散中间态"——公开之前、但已有足够独立验证。2023-2024 年多个 DeFi 协议升级前，链上可观察到这一模式。

### 候选 3: 供给侧启动信号（Supply-Side Activation）

**一句话定义**: 低成本筹码持有方（早期投资者/VC/项目方/Foundation/Treasury）在代币解锁、归属到期或长期静默后，首次出现可辨识的链上行为变化——包括但不限于向 CEX 转入、冷→热钱包转移、大额 Token 流出至非自有地址。

**为什么对基金最重要**:

对于价值型标的，供给侧是价格的"天花板"。一个项目基本面再好、叙事再强、聪明钱再看好，如果其早期投资者的 2 亿美元解锁后开始抛售，短期价格也不可能向上。

**这个信号对价值型基金的重要性远高于对 meme/热点基金的重要性。** 价值型标的几乎都有 VC 融资、团队代币、基金会持仓。这些低成本筹码的持有方就是"悬在头上的剑"。基金需要知道的不是"什么时候解锁"（ECS 会告诉你），而是"解锁后他们做了什么"。解锁后 7 天内无异动 = 最强持有信号之一；解锁后立即转 CEX = 最明确的减仓信号。

**偏向验证 vs 发现**: **90% 验证 / 10% 发现**。几乎纯粹服务于"我们已持仓或已研究的标的是否安全"。供给侧信号对未知标的没什么用（你需要先知道这个标的才能关心它的供给侧）。

**误报风险**: **中高**。主要来源：(1) 正常 Treasury 运营支出（员工薪酬、运营费用）被误读为"出货"；(2) 代币迁移（合约升级、多签更换）被误读为减仓；(3) LP 提供、质押操作被误读为卖出准备。缓解方式：目标地址类型判断（转入 CEX vs 转入协议 vs 转入已知运营地址）是关键区分维度。

**工程复杂度**: **中**。核心难点在于 B1/B2 地址的准确识别——"哪些地址持有低成本筹码"。首版可完全依赖 Arkham 的 VC/Foundation 标签（已覆盖主流项目的主要实体），不自建溯源。行为识别复用候选 1 的 Event Layer。增量工作主要是：维护一个"供给侧关注列表"，将 B 类实体与团队已研究标的做关联。

**历史上为什么有价值**:

代币解锁历来是加密市场最可预测的卖压来源之一。但重点不是解锁本身——市场通常已经 price in 了解锁事件。真正的 Alpha 在于**解锁后的行为**。历史数据表明：解锁后 7 天内开始向 CEX 转入的代币，后续 30 天平均跌幅显著大于解锁后 7 天内无异动的代币。更极端的案例：某些 VC 在解锁前通过链上 Perp 提前做空对冲，然后解锁后立即卖出——这种行为在链上是可追踪的（虽然 Perp 部分应推到 P1）。供给侧信号的核心洞察是：**行为比事件更重要**。

### 候选 4: 主力意图突变信号（Behavioral Regime Shift）

**一句话定义**: 一个在某 Token 上有明确历史行为模式的实体，其最新行为发生了显著偏离——如持续建仓者突然卖出、长期静默者突然激活、一贯分批的实体突然一次性全仓操作。

**为什么对基金最重要**:

候选 1 回答"聪明钱在做什么"，候选 4 回答一个更深层的问题：**"聪明钱是不是改变了想法？"**

一个实体已经连续 3 周在增持某 Token，然后突然停止并开始小幅减仓——这比"某个新实体卖出了一笔"更有信号价值。因为它意味着**之前支撑某个方向判断的人，获得了某种新信息或新评估，导致他改变了策略**。

对于价值型基金来说，"主力意图变化"是所有信号中最能捕捉"拐点"的一类。市场趋势的反转，往往不是从新参与者的行为开始的，而是从**既有参与者行为模式的改变**开始的。

**偏向验证 vs 发现**: **95% 验证**。这个信号几乎只在已跟踪标的上有意义——因为需要历史基线才能判断"偏离"。

**误报风险**: **中**。主要来源：(1) 实体行为基线数据不足导致误判"什么是正常的"（冷启动问题）；(2) 运营性行为变化（更换钱包、策略调整）被误读为意图改变；(3) 小规模操作的随机性被过度解读。缓解方式：设定最小历史交互次数门槛（如该实体在该 Token 上至少有 3 次以上历史操作才触发意图变化检测）；只关注有意义规模的变化。

**工程复杂度**: **中**。不需要完整的 17 维画像体系。核心只需要为每个"实体 × Token"维护一个简化行为基线：(1) 近期净方向（累积/减持/静默）；(2) 操作频率基线；(3) 平均单笔规模。当新行为偏离基线超过阈值时触发。这比 V5 的完整 BMS 简单得多，但捕获了 BMS 最核心的价值——"这次操作对这个实体来说正不正常"。

**历史上为什么有价值**:

这是对冲基金和机构投资中最经典的信号逻辑之一——关注"持仓人的行为变化"而非"新参与者的入场"。传统金融中，13F 报告显示某基金第一次减持其长期重仓股，往往是最具前瞻性的卖出信号。在加密领域，链上数据让这一逻辑可以在日级甚至小时级别执行。2022 年多个大型 DeFi 崩盘前，都可观察到此前最坚定的持有者开始悄悄改变行为——不是大规模抛售（那太晚了），而是**节奏变化、停止增持、小额试探性减仓**。这些微妙信号比绝对金额的变化更具前瞻性。

### 候选 5: 做市商结构异常信号（Market Maker Structural Anomaly）

**一句话定义**: 已识别的做市商实体发生非常规行为——包括撤出做市、新增做市、多个做市商同时调整同一 Token 的报价策略、做市商使用非做市地址进行自营方向性交易。

**为什么对基金最重要**:

做市商是市场微观结构的基础设施。他们的常规行为是噪音（应过滤），但异常行为是极高价值信号：
- **撤出做市**: 做市商比任何人都更了解即将到来的风险（暂停交易、监管行动、团队内部问题），撤出做市是"我不想在这里承担风险了"的最强表达
- **多做市商同向**: 如果 Wintermute 和 Amber 同时减少对某 Token 的做市深度，几乎必然意味着存在未公开的负面信息
- **自营方向性交易**: 做市商用自己的钱（而非做市库存）做方向性押注，信号强度极高

**偏向验证 vs 发现**: **验证 + 风险预警**。主要用于已关注标的的风险判断。

**误报风险**: **高**。做市商行为分析是所有候选中误报风险最高的：(1) 常规库存管理 vs 方向性判断极难区分；(2) 做市商地址经常轮换，标签维护成本高；(3) 做市商的链上可见行为只是其总体策略的一小部分（CEX 端不可见）。

**工程复杂度**: **高**。需要：准确的做市商地址库（持续更新）、做市行为基线建立、常规 vs 异常的分类算法、多做市商关联分析。即便做简化版（只做撤出/新增），仍需解决"什么算撤出"的定义问题（做市商可能只是暂时收窄流动性区间）。

**历史上为什么有价值**:

做市商异常确实是高价值信号——2022 年 Alameda 在 FTX 事件前的异常行为在链上有迹可循；多个做市商同时撤出某 Token 的做市几乎 100% 预示了重大负面事件。问题在于这类信号极其稀少（一年可能只有个位数次真正有意义的做市商异常），且需要深厚的做市商行为理解才能准确识别。信号价值极高，但"价值 × 频率 / 工程成本"的性价比在首版中并不高。

### 候选 6: 新领域关注信号（Smart Money New Frontier）

**一句话定义**: 高质量白名单实体首次与某 Token 产生交互（首次买入），尤其当多个高质量实体在短时间内各自首次进入同一 Token 时。

**为什么对基金最重要**:

"首次参与"在所有链上行为中具有最高的 Alpha 值。加仓可能只是惯性，但首次建仓代表一个全新的投资决策。当一个只投蓝筹 DeFi 的 A1 机构买方首次买入某新协议 Token，这意味着该机构经过研究后认为这个标的值得配置——这对团队来说是"必须看一眼"的事件。

**偏向验证 vs 发现**: **70% 发现 / 30% 验证**。这是 6 个候选中最偏向"发现新机会"的一类，直接服务于 20% 的发现需求。当多个高质量实体首次参与一个团队未覆盖的 Token，这是最值得启动研究的信号。

**误报风险**: **中低**。"是否首次"的判断逻辑简单清晰。主要风险：(1) 实体使用新地址操作导致误判为"首次"（实际上是老持仓者的新地址）；(2) 空投 claim 被误判为主动买入。缓解方式：实体级（而非地址级）的去重 + 排除 claim 事件。

**工程复杂度**: **低**。在候选 1 的基础上，只需维护每个实体的 token 交互历史（一张简单的 entity_id × token_address 表），判断是否首次。增量开发成本极低。

**历史上为什么有价值**:

"Smart Money first mover" 是加密领域最被广泛验证的 Alpha 来源之一。Nansen 的 "Smart Money First Buyer" 标签在回测中显示了持续的正向收益。逻辑很简单：信息优势者的首次行动比跟随行动包含更多信息。但需要注意，单个实体的首次买入信号衰减很快（因为跟踪服务普及，首次买入的信息已经在快速被市场消化），其价值更多在于**多个实体的首次共同参与**——这又回到了候选 2（共振）。

## 三、强制收敛：首版保留的 3+1 类核心信号

经过候选筛选，首版应保留 **3 类核心信号 + 1 类紧密附属信号**。

### 核心信号 A: 聪明钱方向性动作（候选 1）

**为什么必须保留**: 这是 CBS 的根基。没有这个信号，CBS 就不存在。它直接回答基金最高频的决策问题："有没有高质量资金跟我们站在同一边？"

**它覆盖的高价值场景**:

| 场景 | 触发条件 | 投研含义 |
|------|---------|---------|
| 验证已有标的（看多方向） | 高质量实体买入团队已研究标的，且仓位占比高于该实体历史均值 | "聪明钱认真看多，与我们判断一致" |
| 验证已有标的（风险预警） | 高质量实体卖出团队已持仓标的，或出现卖出前兆行为 | "聪明钱在跑，需要立即评估" |
| 为其他模块提供验证 | NDS/ECS 提示某标的有信号 → CBS 查询该标的上的聪明钱行为 | "叙事/事件背后有没有真实资金支持？" |
| 发现新机会（附加标记） | 高质量实体买入团队未覆盖标的 + 标记"首次参与" | "聪明钱发现了新东西，值得研究" |

**它替代了 V5 中的哪些复杂设计**:

| V5 组件 | 处理方式 |
|---------|---------|
| 指标 1（高质量资金净流入/流出）的完整 Z-score 归一化体系 | 简化为：金额 × 实体质量分 × 置信度，不做 [-100, +100] 的复杂归一化，首版用绝对金额 + 质量标签 |
| 指标 2（连续增持/减持天数） | 合并为方向性动作的时间序列维度——同一实体对同一 Token 的连续同向操作自动标记为"持续建仓 N 天" |
| 指标 4（交易所净流量） | CEX 入金/出金作为方向性动作的子类型纳入，不再是独立指标 |
| 完整 BMS 行为匹配分（5 维度 4 标签） | 简化为单维度 conviction：仓位占比 vs 历史均值。> 1.5x = 重注、0.5x-1.5x = 常规、< 0.5x = 试探 |
| 17 项画像指标 + 三层标签 | 简化为实体质量分（quality_score），仅基于：win_rate + avg_pnl + 总交易数 + 最近活跃度 |

---

### 核心信号 B: 多主体独立共振（候选 2）

**为什么必须保留**: 它是把候选 1 从"有意思的线索"变成"可操作的信号"的关键放大器。也是 6 个候选中误报率最低的一类。

**它覆盖的高价值场景**:

| 场景 | 触发条件 | 投研含义 |
|------|---------|---------|
| 最强验证 | 3+ 个无关联高质量实体在 48h 内买入团队已研究标的 | "多个独立信息源指向同一方向，极高置信度" |
| 最高质量发现 | 3+ 个无关联高质量实体在 48h 内买入团队未覆盖标的 | "这是最值得立即启动研究的新标的" |
| 最强风险预警 | 3+ 个无关联高质量实体在 48h 内同时减仓同一标的 | "多个独立决策者同时判断需要退出，必须重视" |

**它替代了 V5 中的哪些复杂设计**:

| V5 组件 | 处理方式 |
|---------|---------|
| 指标 3（高质量资金参与动态）的完整三子维度体系 | 简化为：时间窗口内参与实体计数 + 方向一致性判断，不再计算覆盖率等 |
| 指标 3 的 [-100, +100] 归一化 | 不归一化，直接输出"N 个实体在 Xh 内同向操作，N ≥ 阈值则推送" |
| "多独立实体同向操作"推送条件 | 直接复用，但从"CBS Score 的一个触发条件"升级为"独立的核心信号类型" |

---

### 核心信号 C: 供给侧启动（候选 3）

**为什么必须保留**: 这是价值型基金最独特的需求，也是 CBS 相对于市面上通用鲸鱼追踪工具最大的差异化所在。

**关键洞察**: 通用鲸鱼追踪工具（Nansen、Arkham 的 Portfolio Tracker）追踪的是"谁在买/卖"——这跟信号 A 功能重叠。但"低成本筹码持有方在做什么"是一个更垂直、更少人系统性监控的信号。它直接服务于价值投资的核心风控问题：**供给端有没有即将释放的卖压？**

**它覆盖的高价值场景**:

| 场景 | 触发条件 | 投研含义 |
|------|---------|---------|
| 解锁后行为监控 | B1/B2 实体的 Token 在链上解锁后，首次出现转移行为 | "VC 解锁后在做什么——是准备卖，还是选择持有？" |
| 静默后激活预警 | B1/B2 实体长期静默的地址突然出现活动（冷→热转移） | "沉睡的卖压正在醒来" |
| 项目方行为监控 | B2 实体（项目方/Treasury）出现大额 Token 流出 | "项目方在散货吗？还是运营支出？" |
| 持有信号（反向推断） | 解锁后 7+ 天无异动，或解锁后质押/锁仓 | "低成本筹码选择继续持有，消除悬顶压力" |

**它替代了 V5 中的哪些复杂设计**:

| V5 组件 | 处理方式 |
|---------|---------|
| B1（机构供给方）的 6 种行为模式 | 首版只关注 3 种：转 CEX（减仓）、冷→热转移（前兆）、质押/锁仓（持有）|
| B2（项目方）的 4 种行为模式 | 首版只关注 2 种：大额 Token 转出（散货风险）、回购（看好信号）|
| 指标 6 层 1 中的供给侧事件量化 | 不参与复杂评分，直接作为独立事件推送 |

---

### 紧密附属信号 D: 主力意图突变（候选 4）

**为什么强烈建议保留（但可轻量实现）**:

候选 4 不是一个需要独立数据管道的新信号，而是在候选 1 的基础上增加一个"历史对比层"——它回答的不是"发生了什么事"，而是"这件事对这个实体来说正常吗"。这恰好是 V5 中行为匹配分（BMS）的核心精髓，但 V5 的 BMS 过于复杂（5 维度对比），而首版只需要一个极度简化的版本。

**首版轻量实现方案**:

不需要完整画像基线。只需为每个"实体 × Token"维护 3 个字段：

| 字段 | 定义 | 用途 |
|------|------|------|
| `recent_direction` | 该实体对该 Token 近 30 天的净方向（accumulating / distributing / inactive） | 检测方向翻转 |
| `last_action_days_ago` | 该实体对该 Token 上次操作距今天数 | 检测"静默后激活" |
| `avg_action_size` | 该实体对该 Token 历史操作的平均规模 | 检测"异常规模"操作 |

**当以下任一条件触发时，标记为"意图突变":**
- 方向翻转：近 30 天一直在 accumulating，本次操作为 sell
- 静默后激活：上次操作 > 60 天前，本次操作规模 > $50K
- 异常规模：本次操作规模 > 3× 历史均值

这套机制极度轻量，但捕获了 V5 中 BMS 和 Contrast Layer 想要实现的核心价值。

**它替代了 V5 中的哪些复杂设计**:

| V5 组件 | 处理方式 |
|---------|---------|
| BMS 行为匹配分（5 维度完整对比） | 简化为 3 字段基线 + 3 条触发规则 |
| BMS 输出 4 种标签 | 简化为 1 个布尔标签：is_regime_shift = true/false |
| A 层 6 种风格标签 | 首版不做风格分类，只做意图变化检测 |
| B 层 8 种执行路径标签 | 首版不做 |
| C 层 3 种状态标签 | 首版不做 |
| Contrast Layer 完整框架 | 用这 3 字段基线作为最简替代 |

## 四、明确删除项及理由

### 删除项 1: 做市商结构异常信号（候选 5）→ 延后至 P1

| 维度 | 说明 |
|------|------|
| **删除原因** | 工程复杂度最高、误报风险最高、信号频率极低（一年个位数次真正有意义的事件） |
| **性质** | 高复杂低频——信号价值确实极高，但"价值 × 频率 / 工程成本"性价比在首版不合理 |
| **首版替代** | 做市商的"撤出"和"新增"做市行为，如果 Arkham 标签已覆盖做市商地址，可作为供给侧信号 C 的附属事件监测（不建立独立信号类型）。完整的做市商行为分析体系（区间上下移、库存偏移、自营交易、多 MM 关联分析）全部推到 P1 |
| **重新引入条件** | 当首版 3+1 信号稳定运行后，如果团队发现"基础设施侧的信号缺失"是明显短板，再立项 |

### 删除项 2: 新领域关注信号（候选 6）→ 合并入信号 A

| 维度 | 说明 |
|------|------|
| **删除原因** | 严格来说这不是一个独立的信号类型，而是信号 A 的一个标记属性 |
| **处理方式** | 在信号 A 的每一条事件上附加一个 `is_first_touch: boolean` 字段。当推送时显示为"该实体首次参与该 Token"。当多个实体的 `is_first_touch` 在短时间内触发，自然被信号 B（共振）捕获 |
| **性质** | 不是删除，而是合并——它的价值完全保留，只是不独立成为一个信号类型 |

### 删除项 3: V5 指标 5（持仓集中度变化）→ 延后至 P2

| 维度 | 说明 |
|------|------|
| **删除原因** | 需要全量持仓数据（全量 Token 持有者列表），数据量巨大、成本高。且产出的信号（"零售层占比变化"）对基金实际决策的增量贡献有限——团队关心"谁在买/卖"远多于"持仓分布在变化" |
| **性质** | 高成本低增量。白名单实体的方向性动作信号已经隐含了"高质量资金方向"信息 |

### 删除项 4: V5 指标 7（LP 行为与流动性动态）的完整体系 → 延后至 P1

| 维度 | 说明 |
|------|------|
| **删除原因** | 4 个子维度需要专门的数据管道（V3 Position NFT、Pool 事件），工程成本高。且 LP 行为与基金核心决策（"买不买/卖不卖"）的相关度低于直接的买卖信号 |
| **首版替代** | "撤池 + 深度骤降"这一极端风险场景可简化纳入供给侧信号 C 的附属事件（如果技术上可行），其余 LP 分析全部推后 |

### 删除项 5: Perp 修正项 → 延后至 P2

| 维度 | 说明 |
|------|------|
| **删除原因** | V5 自身已标注为 Phase 2。Perp 仓位归因困难（做市对冲 vs 方向性交易），数据源可靠性待验证 |
| **性质** | 明确的 P2 内容，首版不碰 |

### 删除项 6: 完整三层画像标签体系 → 大幅简化

| 维度 | 说明 |
|------|------|
| **删除原因** | V5 的三层标签（A 层 6 种风格 + B 层 8 种路径 + C 层 3 种状态）需要完整的 17 维画像才能计算。首版信号本身还没跑通，画像精细度的投入产出比极低 |
| **首版替代** | 一个 `quality_score` (0-100) + 一个 `entity_class` (A/B/C1/D) + 信号 D 的 3 字段基线。总共 5 个字段，替代 V5 的 17 项指标 + 16 种标签 |

### 删除项 7: M5 自动回测与画像反馈闭环 → 延后至 P1

| 维度 | 说明 |
|------|------|
| **删除原因** | 回测是"优化已有系统"的能力。前提是系统已在稳定产出信号。首版应先保证信号能产出并推送 |
| **首版替代** | 人工记录每条推送信号后 7 天、30 天的价格变化，每周团队复盘。足以在首版阶段评估信号质量 |

### 删除项 8: 自建实体归因（4 种方法）→ 延后至 P2

| 维度 | 说明 |
|------|------|
| **删除原因** | Gas 分析、资金流聚类、时序聚类、合约工厂追踪——每一种都是独立的技术项目。首版直接使用 Arkham/Nansen 已有的实体-地址映射 |
| **首版替代** | 第三方标签 + 投研手动补充。自建归因是 P2 的竞争力项目 |

## 七、一句话最终判断

> **模块二首版最核心应该服务的是：帮助团队持续回答"我们研究的标的上，高质量资金的真实方向是什么、有没有变化、供给侧安全吗"——这三个问题。最不该优先做的是：在首版中追求指标体系的完备性（7+1 指标、完整画像、自动回测），因为完备性不产生信号，只优化信号，而首版的任务是先让信号跑起来。**

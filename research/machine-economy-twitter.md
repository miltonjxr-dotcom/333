## 3. 从这些观点抽出的监控指标

这些人真正在争论的，不是“机器经济有没有”，而是 **产能已经很大，成交有没有跟上**。投资时钟也卡在这里。

诊断量（不是第 7 个指标，是读数规则）：

> **转化率 ≈（推理/API 支出 + 付费物理劳动）的增量 / （数据中心用电 + hyperscaler capex）的增量**

产能涨、转化率不升 = 建设/叙事期，机会在铲（电、芯片、结算轨），不在应用代币。  
转化率升 = 机器进入真实循环，再往使用层和下层应用加权重。

### 抓时机：四条触发，不靠体感

现在（2026-08）的默认判断：L2 建设期，L3 基础设施先行、成交是噪声。所以——

1. **还在建设期（转化率不升）**  
   机会在约束环节：电力、并网、先进封装、存储、DC 建设。Dylan / SemiAnalysis 的瓶颈切换（电 → 芯片 → ASML）比任何 agent 叙事更接近可交易信息。  
   **不要**因为 x402 基金会成员名单去买协议币。

2. **L3 从刷量变成生意（这才是 crypto/agent 的入场钟）**  
   同时满足，而不是只满足一条：  
   - Artemis 洗量占比持续下降（笔数和金额同向改善）  
   - 均价不再靠亚分 ping 撑笔数（Gökhan：counts 跌、value 持平或升 = 质量改善）  
   - 卖方收入去集中化（现在 BlockRun 一类可占笔数八成；去集中化才说明出现第二、第三类刚需）  
   - 独立口径收敛（x402.org / Allium / Artemis 不再差一个数量级）  
   触发之后，看的是 **facilitator、发现层、稳定币结算、无头 API 商户**，不是人格 Token。

3. **使用追上 capex（云/软件的入场钟）**  
   云厂商可分离 AI 收入增速 ≥ capex 增速，且 OpenRouter/Ramp 的付费调用不掉。这是从“买铲子”切到“买使用”的条件。BIS 已经把 capex > FCF 写成风险；反转才是加仓使用层。

4. **生产率差出现（确认钟，偏晚）**  
   高 AI/自动化暴露部门的劳动生产率相对其余部门转正且持续。来了说明宏观叙事成立，价格往往已经部分反映。用来减杠杆、验证，不用来抄底主题。

### 一张对照：推特在吵什么 vs 指标怎么用

| 推特常见说法 | 对应指标 | 怎么用 |
|--------------|----------|--------|
| “agent 支付爆了” | 指标 4，Real vs Gamed | 先看洗量。Levine/Shin 已经演示过 $24M 可以变成 $1.6M |

| “人形元年” | 指标 6，不是融资新闻 | 付费行程/仓机小时；演示视频作废 |

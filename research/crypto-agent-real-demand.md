# Crypto Agent 真实需求研究

**研究日期：** 2026-08-26  
**方法约束：** 不以融资、Token 市值、Agent 数量为需求成立的证据；优先使用付费、成交、留存、链上执行和可核对案例。

---

## 0. 结论先讲

用户的核心假设——**人们使用 Crypto Agent，是为了改善经济结果**——作为资本所有者的主动机，**大体成立，但作为完整需求理论过于狭窄**。

它漏掉了四件同样真实、且能解释大量“Agent 使用”的东西：

1. **使可能，而不只是使更好。** 许多链上机会的半衰期以秒计（清算、CEX–DEX 套利、开盘狙击）。人做不到，不是“省时间”，是能力边界。
2. **竞争性强制。** 对手盘已经是机器人。没有自动化，你不是选择手动，你是选择当猎物。
3. **保险与值班价值。** 清算保护即使从未触发，也值一笔保费。这不是“新增收益”，是睡眠与尾部风险的定价。
4. **负期望值仍可有需求。** 网格、狙击、跟单里有大量用户在付费购买彩票、控制系统的幻觉，或缓解焦虑。有使用 ≠ 有正 EV。

因此：

> **真实需求 = 有人用自己的钱、反复为某一项工作付费，且这项工作来自加密市场的结构约束，而不是来自 Token 叙事。**  
> 伪需求 = 把 Agent 当可交易资产、空投刷量、或把聊天机器人套上钱包后称为“经济主体”。

按这个标准，2026 年的地图很清楚：

| 层级 | 状态 | 代表 |
|------|------|------|
| 专业提取与协议维持 | **已验证** | MEV searcher、清算机器人、intent solver、keeper |
| 资本所有者的风控与执行 | **已验证** | 清算保护、限价/DCA/TWAP、MEV 防护成交 |
| 零售交易自动化 | **使用已验证，EV 未普遍验证** | 网格/组合机器人、Telegram 狙击 |
| LLM 包装的“AI Agent” | **大多未验证或伪需求** | 人格 Token、Agent 发射台、A2A 工作市场 |
| x402 / Agent Commerce | **基础设施先行** | 洗量后真实商务仍是噪声级 |

**未来真正值得关注的需求，不是“更多 Agent”，而是少数结构问题：24/7 值班、对抗性提取、秒级机会、复杂执行、协议清偿。** LLM 只有在进入这些工作的执行环、并且费用来自本金而非激励时，才从叙事变成需求。

## 1. 第一性原理：什么才算 Crypto Agent，什么才算真实需求

### 1.1 先定义 Agent，否则所有数字都不可比

加密里被叫做 Agent 的东西，至少有四类，经济含义完全不同：

| 类型 | 实际是什么 | 人是否逐笔确认 | 例子 |
|------|------------|----------------|------|
| **A. 专业机器人** | 低延迟策略代码 | 否 | MEV searcher、清算 bot |
| **B. 规则自动化** | 用户设触发条件，keeper 执行 | 否（设好之后） | DeFi Saver、Jupiter DCA、Yearn 复投 |
| **C. 意图求解器** | 用户签意图，solver 竞价成交 | 否（成交细节） | CoW / UniswapX / 1inch Fusion |
| **D. LLM 代理** | 语言模型规划并调用工具/钱包 | 视产品 | Eliza 人格、Bankr 自然语言下单、Virtuals ACP |

A–C 在 LLM 叙事出现之前已经存在十年。它们是加密市场对 **24/7、可代码化、对抗性** 结构的应答。D 是新包装。研究需求时，必须按**工作**分类，不能按是否自称 Agent 分类。

操作定义：

> Crypto Agent = 在用户（或协议）给定目标与约束后，能在**该次**链上/交易所行动中不经人确认而改变资金状态的软件。

聊天、研报、发推、发 Token，若没有改变资金状态，不是这里要测的需求。

### 1.2 真实需求的操作标准（四条，缺一不可）

1. **谁付钱：** 终端用户或协议用自己的本金/费用预算付，而不是用积分、空投、激励池付。
2. **是否反复：** 同一工作在叙事冷却后仍发生。Virtuals 费用从单周约 92 万美元掉到约 7.5 万美元，是反例。
3. **替代方案更差：** 相对“手动 / 更简单的脚本 / 什么都不做”，风险调整后结果更好，或根本不可行。
4. **工作来自结构约束，不是来自叙事。** 结构约束见第 4 节。

用 Token 市值、发射 Agent 个数、x402 原始笔数证明需求，全部违反 1 或 2。

### 1.3 伪需求的常见形态

| 形态 | 看起来像需求 | 实际是 |
|------|--------------|--------|
| Agent 发射台 | “数万个 Agent” | 一级/二级 Token 投机。Virtuals：约 152 亿美元 Agent Token 成交 vs 约 450 万美元任务收入，每 1 美元服务对应约 3300 美元 Token 换手 |
| 激励下的 A2A job | “完成了百万级任务” | 单均 <2 美元，且有月度激励计划，模拟商务的利润可以高于真商务 |
| LLM 发 meme | Clanker “AI 部署代币” | 需求是发盘与交易 meme；LLM 只是发行按钮。费用随 meme 周期剧烈起伏（Clanker 协议收入 2026Q1 约 3514 万美元，2026Q3 约 46 万美元量级） |
| 把聊天机器人代币化 | AIXBT 类 | 媒体/注意力产品，Token 定价远高于其作为研究工具的收费能力 |
| 原始 x402 笔数 | “机器在付钱” | Visa×Artemis：约 89% 应洗掉；洗量后至 2026-04 约 1500 万美元，均价掉到数美分 |

## 2. 对“用户用 Agent 就是为了改善经济结果”的评判

### 2.1 假设里对的部分

对**持有可观本金、目标是财富期望值**的人，四个来源是对的：

- 多赚钱：发现并执行人来不及执行的机会  
- 少亏钱：防清算、防夹子、自动止损  
- 少花钱：更好的路由、批量拍卖、Gas 抽象  
- 节约注意力：把 24/7 值班外包  

加密比传统金融更强迫这四件事成立，因为市场不停、对手是机器人、错误不可逆。

### 2.2 必须补充的动机（否则解释不了真实使用）

**（1）能力扩展，不是优化。**  
清算窗口、同一区块狙击、跨所套利，人的反应时间不够。需求函数不是 `更好的 PnL`，是 `从 0 到 1 的可行性`。专业 searcher 年利润仍以亿美元计（以太坊 MEV 利润粗估每年 2.5–3 亿美元量级，随波动剧烈变化），但这不是零售“多赚一点”，而是少数团队的生产函数。

**（2）竞争性强制 / 避免成为猎物。**  
夹子攻击在以太坊上一年可造成约 6000 万美元量级的交易者损失。用户去 CoW / UniswapX，常常不是为了“多赚 0.5%”，是为了**不要被抽走**。这仍是经济结果，但心理账户是防御，不是进攻。

**（3）保险与值班，独立于实现收益。**  
DeFi Saver 在 2026 年 6 月末约 **2.81 亿美元**抵押品、**867** 个仓位处于自动化管理；官网同时给出自动化管理 ATH 约 15 亿美元、累计执行量约 15.2 亿美元。用户为“睡眠时不被清算”付 Gas 和 0.25% 复杂交易费。即便当月一次都没触发，需求仍然成立——这是保费，不是收益。

**（4）赌博、控制系统、身份。**  
网格机器人在趋势市结构上 EV 为负（Bitsgap 自己的 H1 2026 数据：GRID 月度启动占比从 41% 掉到 30%，启动量腰斩，因为市场在趋势而非震荡）。小账户订阅费可构成两位数年化拖累。人们仍在用。底层动机经常是：高胜率的小盈利带来控制感；或“我有一套系统”。Telegram 狙击机器人累计成交可达百亿美元（Banana Gun 自称 160 亿美元+、2400 万笔），费用随 meme 周期暴涨暴跌——这是彩票需求，不是资产配置需求。

**（5）协议侧需求，用户不是买方。**  
借贷协议必须有人清算，否则出现坏账。这是协议为清偿力购买的公共服务，searcher 赚的是奖金。Chainlink SVR 把这部分 MEV 回收给协议：处理数亿至约 7 亿美元清算名义、回收约千万至 1.87 亿美元量级（不同口径），Aave 等用治理投票加深集成。买方是协议，不是“零售 Agent 用户”。

**（6）把 Agent 当股票。**  
Virtuals 上大多数“使用”是交易 Agent Token。Robinhood Chain 上线带来的流量在数周内 DEX 成交 −83%、活跃钱包 −80%、周费 92 万 → 7.5 万。这是发行与注意力，不是对 Agent 劳动的需求。

### 2.3 直接回答：判断是否过于狭窄

**是，过于狭窄。** 更准确的说法：

> 资本所有者使用执行类 Agent，主目标是改善**风险调整后的经济结果**（含保险与可行性）。  
> 但加密里大量被称为 Agent 的使用，其实是：专业提取、协议维持、彩票、注意力和 Token 投机。  
> 若把后四类也算进“用户为了赚钱”，会把负 EV 和伪需求算成产品市场契合。

## 3. 当前用户为什么用：底层动机分层

把“谁在用、付什么、图什么”拆开，比问“Agent 有没有需求”有用。

| 使用者 | 付费方式 | 底层动机 | 需求真实性 |
|--------|----------|----------|------------|
| MEV / 清算团队 | Gas、builder bribe、基础设施 | 把毫秒级价差变成利润；赢家通吃 | 已验证。净利率被竞价压到很低，但工作不会消失 |
| Intent solver | 价差、协议激励 | 竞价获得成交权，赚执行剩余 | 已验证。CoW 单月可达约 40 亿美元成交、约 4.8 万活跃钱包 |
| 杠杆存款人 | 执行时从仓位扣 Gas/手续费 | 防清算、自动调杠杆、睡觉 | 已验证。仓位级留存强于“日活” |
| 现货/合约交易者 | 订阅或按笔 | DCA/限价/网格/跟单；混合了执行质量与赌博 | 使用真实；策略 EV 分化极大 |
| Meme 狙击手 | 0.5%–1%/笔 | 速度彩票；反 Rug 是附带 | 使用真实、高度周期性；多数人期望值为负 |
| 收益存款人 | 业绩费（如 Yearn 约 10% 的收益分成） | 把复投、选池、Gas 外包 | 已验证但规模从周期高点大幅回落（TVL 约 2 亿美元量级仍在） |
| 协议/DAO | 向 keeper/oracle 付费 | 收获、清算、限价单成交、epoch 维护 | 已验证。通用“Web3 Functions”作为独立产品并不稳（Gelato Functions 于 2026-03-31 关停），专用清算/预言机更稳 |
| LLM Agent Token 持有人 | 买卖 Token | 赌叙事 | 伪需求（对 Agent 劳动而言） |
| 用自然语言下单的人 | 交易手续费 | 降低操作摩擦 | 有潜力：需求是“更好的交易入口”，不是“自主经济主体” |

**动机的一句话：**  
专业用户买的是**速度与独占**；稳健资本买的是**值班与执行质量**；零售经常买的是**希望与省心**；投机者买的是**Agent 这个名词的票**。

## 4. 已证明能改善经济结果的场景

只列能指出机制、且有付费或链上执行证据的。公司累计成交（如 3Commas “4000 亿美元、100 万注册”）只作量级参考，不当核心证据——累计值不可逆，不证明当前留存或正 EV。

### 4.1 增加收益（已验证的是专业层；零售层很少被证明）

**CEX–DEX / DEX 套利、背跑清算。**  
工作本身创造利润。EigenPhi 等口径：以太坊 MEV 在 2022-12 至 2025-01 约 9.63 亿美元收入、4.17 亿美元利润；近 30 天快照可到约 2400 万美元利润。Searcher 把毛利的大部分（常 90%+）付给 builder/验证者。  
**这证明需求，也证明租金被基础设施抽走。** 对零售“AI 交易 Agent”几乎没有可迁移的 alpha。

**清算奖金。**  
Aave+Compound 以太坊清算累计给 searcher 约 1.3–1.5 亿美元利润量级（名义清算远大于此）。波动日利润陡增。这是协议设计出来的、必须被完成的工作。

**自动复投与策略金库。**  
Yearn 一类金库把选策略、复投、Gas 摊销做成存款。2026 年 TVL 约 1.8–2.3 亿美元，仍产生费用。相对 2021 年高峰已经缩小，但**多年后仍有人付 10% 业绩费**，说明“懒得自己 compound”是真需求，只是可外包的超额收益变薄了。Pendle、循环贷、自动杠杆则更多是收益形状选择，不一定是 Agent。

**网格/高频零售机器人：使用真实，收益未普遍验证。**  
Bitsgap H1 2026：81,456 次机器人启动、1260 万笔成交，九成仍在中心化交易所。COMBO/DCA 在趋势市接手 GRID 的份额，说明用户会换策略，不是纯一次性尝鲜。但平台数据是**启动与成交**，不是用户净 PnL。独立费用拆解显示：小账户订阅可造成高年化拖累，网格在趋势中会堆库存。  
**分类：有付费使用；“能增加收益”对平均用户不成立。**

### 4.2 避免损失（这是零售侧最硬的已验证需求）

**清算保护 / 自动偿还 / 目标抵押率。**  
机制：清算罚金通常是抵押品的高个位数百分比；自动化在阈值处偿还或平仓，费用是 Gas + 约 0.25% 复杂交易费。不等式很简单：`自动化成本 << 清算罚金 × 触发概率`。DeFi Saver 的规模（约 2.5–2.8 亿美元处于自动化、历史执行量十亿美元级）和用户在闪崩后的公开反馈，是留存证据。自动化管理的仓位数以百计而非百万——这是**高净值、高杠杆**需求，不是大众社交需求。

**MEV 防护成交。**  
夹子是隐形滑点。Intent 拍卖把订单拿出公共 mempool，solver 竞争改善价格。CoW 2026 年 4 月：约 29.3 万笔、4.77 万活跃钱包、**40 亿美元**成交；另有月度更高的历史（如某月以太坊上 112 亿美元）。公开比较常给出相对 AMM 约 **0.3%–0.8%** 的价格改善。用户反复来这里换大单，是“少亏”的付费意愿。

**止损 / 移动止损 / 限价。**  
Jupiter 等把限价和 DCA 做成非托管 + keeper。DefiLlama 上 Jupiter DCA 交易费在 2025Q1 单季约 310 万美元，随后随市场降温下滑（2026Q2 约 20 万美元、2026Q3 初更低）。这正好说明：**需求真实且亲周期**，不是永远高增长的“Agent 赛道”。有波动、有本金要分批进场时，人们付钱；平静期就停。

### 4.3 降低成本（已验证，但是成交基础设施，不是“智能体人格”）

- **批量拍卖 / Coincidence of Wants：** 部分成交完全不对 AMM 支付，节省 Gas 与价差。  
- **Solver 代付 Gas：** UniswapX 等产品上相当比例成交由 solver 承担 Gas，用户少持有原生代币。  
- **聚合路由：** Jupiter 在 Solana 现货聚合中的份额长期极高——需求是最优路径，keeper 只是限价/DCA 的执行臂。  
- **协议回收 OEV：** SVR 让清算 MEV 从匿名 searcher 回到协议金库，改变的是租金归属，不是创造新交易。

这些都不需要 LLM。

### 4.4 节约有经济价值的时间（真实，但计价方式不是时薪）

加密里“时间”几乎从来不是“少点几次按钮 × 时薪”。更贵的是：

- **在岗义务：** 杠杆仓位要求你在任意时区盯健康因子。自动化买的是下班权。  
- **操作复杂度：** 跨协议偿还、抵押品替换、限价+DCA 组合。出错的成本是本金，不是多花 20 分钟。  
- **Gas 时机：** 复投若手动，要么频繁付贵 Gas，要么错过复利。金库把这件事摊到大额 TVL 上。

Yearn、DeFi Saver、Jupiter DCA 的共同模式是：**用户做一次意愿表达，执行次数 >> 1。** 这才是可验证的时间需求。  
LLM 对话式“帮我看看该买什么”若仍要人确认并自行下单，节约的是搜索时间，通常低于它引入的幻觉与代理风险。

## 5. 为什么这些场景会产生真实需求：结构原因，不是产品名单

加密自动执行的需求，来自市场设计，不是来自模型发布。

**约束 1：连续时间。**  
传统市场有收盘。加密没有。任何依赖健康因子、资金费、清算线的仓位，都把持有人变成无薪值班员。于是出现两类买单：自己写 bot，或向 DeFi Saver 这类服务买触发器。

**约束 2：对抗性、可观察的内存池。**  
交易在被打包前是公开猎物。提取是均衡策略。于是出现两种对称需求：进攻（searcher）和防御（私有订单流、批量拍卖）。一边消失，另一边也会变形，但**不会回到人工点击**。

**约束 3：机会的半衰期极短。**  
清算奖励给第一笔成功交易；开盘流动性给同一区块的买家。期望收益对延迟极度凸。这创造专业 Agent 市场，并筛掉 LLM——语言模型的规划延迟和不可重复性，在这些市场里是致命缺陷。**真实的高收益 Agent 需求，天然排斥当前的 LLM Agent 形态。**

**约束 4：错误不可逆、惩罚函数非对称。**  
清算罚金、永久损失、被夹，都是左尾。前景理论下，人对左尾的支付意愿高于精算保费。所以风控自动化可以在“很少触发”时仍被购买。这是需求，不是用户非理性到不可理解——他在买凸性。

**约束 5：策略可被代码完全表达。**  
链上状态 + 可组合合约，使“若比率 < X 则偿还”成为确定性程序。确定性工作会被自动化，这是科斯定理在 gas 成本下降后的结果。LLM 的比较优势不在这里，而在**尚未被形式化的意愿**（“把风险压到我睡得着的水平，并在资金费率倒挂时减杠杆”）。后者有潜力，尚未被大规模付费验证。

**约束 6：协议是机器，必须请机器来维护。**  
没有 keeper，限价单不会成交，金库不会 harvest，清算不会发生。协议用费用买可靠性。Gelato 关掉通用 Functions、Chainlink 把 Automation 迁到 CRE，说明**通用计算网络**不好卖，**绑定清偿/预言机/跨链的专用执行**好卖。需求在工作上，不在“自动化平台”品类上。

**约束 7：零售的操作界面极度差。**  
多链、多钱包、授权、Gas。Telegram 机器人用托管私钥换来“在聊天里一键买”。人们付 0.5%–1% 费率，买的是延迟下降和界面，代价是托管风险。需求真实，但是**对更好入口的需求**，被包装成 Agent。

这些约束预测了什么会继续存在：值班、防御提取、秒级竞赛、确定性触发、协议维护、更顺滑的执行入口。  
也预测了什么会反复以叙事出现又冷却：会聊天的钱包、Agent Token、为微支付而微支付。

## 6. Agent-to-Agent、x402、Agent Commerce：哪些是真需求

### 6.1 已经是真需求的部分（但通常不叫这个名字）

- **Solver 之间、searcher 与 builder 之间的机器对机器竞价。** 这是成熟的 A2A。它不需要 x402，已经跑在 Flashbots、MEV-Boost（约 90% 以太坊区块）和 intent 拍卖里。经济问题是：**分配瞬时执行权**。  
- **Keeper 网络按条件调用合约。** 机器为协议工作并领取费用。经济问题是：**把链下观察接到链上状态转换**。  
- **自动做市与库存机器人。** 机器对机器提供流动性。经济问题是：**连续报价**。

这些需求在“Agent Commerce”一词流行之前就付费了。

### 6.2 基础设施先行、商务未成立

**x402。** HTTP 402 作为 Agent 拉 API 的付款轨道，工程上合理：机器调用是小额、高频、按次的。Visa×Artemis 洗量后至 2026-04-21 约 **1.096 亿笔 / 1500 万美元**；2026-08 公开累计约 1.68 亿笔 / 4140 万美元量级；均价落到约 4 美分；独立研究指出原始额约 89% 应剔除。  
**判断：** 轨道在被锻炼，**买方商务几乎尚未出现**。笔数增长而金额不增长，是信令，不是商业。

**Virtuals ACP / 自报 aGDP。** 发射与 Token 成交是真的（百亿美元级换手）；任务收入约 450 万美元、单均不足 2 美元；还有激励计划。Robinhood 流量证明发行分发可以突然很大，留存证明劳动需求没有接住。  
**判断：** 资本市场层是真投机需求；劳动层未验证。

**Bankr 等“社交里下单”。** 累计费用可到数百万美元，但与 Base 上 meme 发行周期绑定。需求更接近 Telegram 机器人的自然语言版：降低摩擦。是否变成自主 Agent 商务，取决于人是否不再确认——目前多数产品仍是人在环内的指令界面。

**Clanker。** 费用真实且曾极大，本质是 **AI 外观的 Pump.fun**：需求是发币与交易，不是 Agent 劳动。

### 6.3 仍是叙事的部分

- “Agent 自己赚钱付自己的推理账单”作为规模化现象  
- 机器之间就任意服务发现、谈判、履约、评价的开放市场  
- 用 Agent 数量、aGDP、未洗量笔数描述的“机器经济已切换”

这些可以作为基础设施赌注，不能作为已经验证的用户需求。

## 7. 公式是否可用，以及更合理的判断框架

### 7.1 原公式

> Agent Value = 新增收益 + 避免损失 + 节约成本 + 节约时间价值 − Agent 成本 − 新增风险

对**单一资本所有者、单一策略、风险中性**的事后复盘，方向正确，且比“看市值”好得多。用作是否成立的充分条件，**不完整**。

### 7.2 主要缺陷

1. **没有对照。** 必须是相对次优方案的增量，不是相对零。相对“什么都不做”，任何会动的网格都像在创造价值。  
2. **没有期望与分布。** 网格的小赢 + 趋势爆仓，算术平均可能为正、期望为负，或反过来。要用 `E[ΔW]` 和左尾，而不是某段回测。  
3. **保险价值未被计入。** 未触发的清算保护：新增收益 = 0，避免损失 = 0（本路径没出事），但效用为正。应加 `保费等价`。  
4. **时间价值不是工资率。** 正确的是“24/7 在岗的影子价格”和“操作出错的期望损失”。对杠杆用户，这个数字接近清算罚金，而不是时薪。  
5. **没写清是谁的价值。** Searcher 的新增收益常常是用户的新增损失。协议回收 OEV 改变分配，不改变总和。必须标明主体：用户 / 提取者 / 协议。  
6. **新增风险往往是主项且被低估。** 策略制度错配、LLM 幻觉下单、Telegram 托管私钥、金库的组合合约风险、激励刷量导致的虚假信号。  
7. **不能解释负 EV 需求。** 彩票、身份、叙事投机会显示为公式里的负值，但使用仍在。那些不是“Agent 劳动需求”。  
8. **没处理竞争性强制。** 有时价值是“避免相对对手的劣势”，公式里没有这项。

### 7.3 更合理的两层框架

**第一层：经济价值（给资本所有者）**

\[
V = \mathbb{E}\big[\Delta W \mid \text{Agent}\big] - \mathbb{E}\big[\Delta W \mid \text{次优方案}\big]
\]

其中 \(\Delta W\) 已计入费用、Gas、滑点、清算、机会成本。再单独报告：

- **左尾：** 95%/99% 分位损失、最大回撤、是否存在爆仓路径  
- **保险项：** 用户为“不值班”愿意付的保费上限 ≈ 清算罚金 × 主观崩盘概率  
- **可行性项：** 若次优方案是“无法执行”，则 \(V\) 就是 Agent 的全部期望利润（MEV 类）

**第二层：需求是否成立（揭示偏好）**

仅当同时满足：

1. 有人用**非激励**资金反复付费；  
2. 叙事冷却后量不会掉一个数量级（对比 Virtuals 周费）；  
3. \(V\) 对目标主体 ≥ 0，或 \(V<0\) 但用户明确在买彩票/媒体——后者不要当成金融 Agent 需求；  
4. 新增风险被用户理解且可关闭（非托管、可关触发器、可限制授权）。

**一句话规则：**  
先问“这是值班、防御、秒级竞赛、还是彩票/发行？”再决定套不套收益公式。彩票和发行不要用收益公式来证明产品成立。

## 8. 未来真正值得关注的需求：各自解决什么经济问题

去掉叙事后，值得长期看的只有这些问题。LLM 是可选实现，不是问题本身。

| 经济问题 | 为什么不会消失 | 已验证形态 | LLM 是否必要 | 监测什么 |
|----------|----------------|------------|--------------|----------|
| **1. 24/7 杠杆值班** | 市场不停、清算非对称惩罚 | 自动偿还、目标比率、止损 | 否。自然语言设策略是 UX | 自动化管理的抵押品、触发次数、相对清算罚金的费率 |
| **2. 对抗性提取与反提取** | mempool 或等价信息泄漏将长期存在 | MEV、SVR、intent 拍卖 | 否 | 洗量后的成交剩余、夹子损失、协议回收额 |
| **3. 瞬时执行权分配** | 清算/套利/开盘是竞速 | searcher、solver、builder | 否，且 LLM 有害 | 利润总额与集中度，而不是 bot 个数 |
| **4. 意愿到成交的执行质量** | 用户要的是结果不是路径 | DCA、限价、TWAP、聚合 | 否 | 费用、成交量、相对 AMM 的滑点；亲周期性是正常的 |
| **5. 协议状态机维护** | 链不会自己 harvest | keeper、Automation/CRE | 否 | 非激励的 upkeep 付费；通用自动化平台的关停是反面教材 |
| **6. 收益运营外包** | 复投与选池有固定成本 | 金库、auto-compound | 否 | 业绩费是否还能收得动、TVL 是否只随激励波动 |
| **7. 高摩擦入口** | 多链操作对零售仍然差 | Telegram/社交下单 | **可能**（自然语言） | 手续费是否在 meme 退潮后仍在；托管事故率 |
| **8. 非形式化意图** | “按我的风险睡着”很难写成单一阈值 | 几乎没有规模化产品 | **这是 LLM 唯一的结构性入口** | 是否出现授权限额内的反复无人确认执行，且 PnL 分布可接受 |

**不值得当成已验证需求去追的：** Agent 发射台、Agent GDP、A2A 开放劳动市场、为 API 微支付而刷 x402、会发推的钱包 Token。

**对建设者的含义：**  
先嵌入问题 1–6 的执行环（风控触发、成交、清算、金库），再考虑 LLM。先做 D 类人格、再找工作，是 2024–2026 年已经失败过一轮的顺序。

**对投资人的含义：**  
付费成交、触发执行、协议费用，可以当需求。Agent 个数、Token 换手、未洗量笔数，不能。Clanker/Banana Gun/Virtuals 的费用曲线已经演示：同一套“Agent”外表下，真实的是发行与赌博周期。

## 9. 五句收束

1. **真实需求来自加密市场的结构：不停市、对抗、秒级、不可逆、协议必须被机器维护。** 不来自模型能聊天。  
2. **“为了赚钱”只覆盖专业提取者和一部分资本所有者。** 零售大量需求是少亏、值班、彩票和更顺的入口；把后两者算成金融 alpha，会持续误判。  
3. **已验证且可规模化的，几乎都是确定性规则 + keeper/solver，不是 LLM Agent。** 清算保护、intent 成交、DCA/限价、MEV 供应链，证据在执行量和反复付费上。  
4. **x402 / A2A / Agent Commerce 目前是轨道和发行，不是劳动市场。** 洗量后的商务和任务收入相对 Token 换手可以忽略。  
5. **判断公式要用期望增量财富相对次优方案，并单列保险、左尾、主体和揭示偏好。** 原四项加减法可用作清单，不可用作是否成立的充分统计量。

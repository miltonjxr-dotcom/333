# 机器人产业底层环节长期投资研究

本仓库存放一份买方研究备忘录，回答：

> 随着机器人产业长期增长，哪些底层硬件、软件、平台或系统能力具有最高的跨场景通用性、增长弹性和长期价值捕获能力？

完整报告见 [`research/robotics-industry-value-capture.md`](research/robotics-industry-value-capture.md)。

研究覆盖工业机器人、协作机器人、AMR/AGV、仓储、四足、人形、无人机、无人矿卡、农业、建筑、医疗、军用、巡检、ROV/AUV、家庭服务等形态，不以人形供应链代替整个产业。

核心结论（五条）：

1. 最通用的底层能力是闭环控制物理世界：感知、任务理解、实时运动控制、部署后运维。
2. 已验证的最高壁垒硬件是高端运动控制闭环，不是减速器、丝杠或灵巧手。
3. 未来潜在最高壁垒的软件更可能是数据/工作流/仿真闭环，而不是单独可售的 VLA。
4. 长期利润池更可能在运动控制与系统级执行器、高切换成本场景系统、物理 AI 训练/仿真基础设施。
5. 若只跟踪五个方向：高端运动控制、场景级系统与运维、物理 AI 算力与仿真、系统级执行器、车队软件与数据闭环。

报告严格区分事实、推断、假设；关键缺口标为无法确认。不是投资建议。
